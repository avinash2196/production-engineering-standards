# History

Gap briefs record what real PDD runs showed about the plugin, and the fixes that followed. Each brief is one batch, released as one plugin version.

| Brief | Status | Release |
| --- | --- | --- |
| [pdd-gap-fixes-2026-10.md](pdd-gap-fixes-2026-10.md) | Closed | 0.12.0 |
| [pdd-gap-fixes-2026-10-b.md](pdd-gap-fixes-2026-10-b.md) | Closed | 0.14.0 |
| [pdd-gap-fixes-2026-10-c.md](pdd-gap-fixes-2026-10-c.md) | Open | Next release |
| [pdd-gap-fixes-2026-11-d.md](pdd-gap-fixes-2026-11-d.md) | Draft (code quality, review, API conventions) | After 0.15.0 |

Each finding is classified as **Plugin** (the plugin text was missing or unclear, so it gets a fix) or **Model** (the plugin already stated the rule and the model broke it, so there is no change). Project names in the briefs identify the evidence runs only. They are never plugin rules.
