# Planning Artifacts

This directory contains repository-maintenance planning artifacts used to demonstrate and exercise the Prompt-Driven Development workflow.

- `Plan.md` records the most recent repository-level convergence plan and its acceptance criteria.
- Numbered Implementation Plans are historical execution artifacts from earlier repository milestones.
- Historical artifacts are evidence of earlier work, **not active engineering standards**. Current normative guidance lives under `standards/`, `.github/`, `playbooks/`, and the current templates.
- A new qualifying repository change should update `Plan.md` and create a new phase-specific Implementation Plan rather than treating a completed historical plan as authorization.
