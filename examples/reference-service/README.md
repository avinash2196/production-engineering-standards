# Reference Service Adoption

This folder demonstrates what an application using the standards repository would own.

```text
reference-service/
  .github/
    copilot-instructions.md
  docs/
    .ai/
      Plan.example.md
      001_Implementation_Plan_RED.example.md
```

The application does **not** copy the entire standards repository. Agents/skills are registered through the supported customization mechanism, while task artifacts remain in the application.
