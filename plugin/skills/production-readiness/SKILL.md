# Production Readiness

Review evidence for:

- functional and failure-path tests
- capacity/latency risk where material
- configuration and secrets
- observability and alerting
- dependency failure behavior
- database/schema/data migration
- compatibility during rollout
- deployment ordering
- rollback/recovery
- runbook/ownership
- known residual risks

Production readiness is a decision supported by evidence, not a checklist score.
