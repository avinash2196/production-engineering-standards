# Architecture Decision Record (ADR) Template

Purpose
- Standard ADR template to capture significant architecture decisions, their context, trade-offs, and consequences.

Placeholders
- Title: <DECISION_TITLE>
- Status: Proposed|Accepted|Deprecated
- Context: <What led to this decision>
- Decision: <What is being decided>
- Consequences: <Implications>

Config and fallback notes
- Document how this decision affects config keys and fallback behavior (e.g., enabling local queue when Kafka unavailable).

Infra dependencies
- List services affected and any required infra changes.

Reviewers
- List architecture, security, and compliance reviewers.
