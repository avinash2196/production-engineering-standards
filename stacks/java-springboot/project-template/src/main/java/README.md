# Java Project Template — Source Layout

This directory contains the standard Java package structure generated by the scaffolding agent.

## Package Structure

```
com/myorg/{servicename}/
├── controller/              # REST controllers (thin — delegates to service)
│   └── dto/                 # Request/Response DTOs (Java records)
├── service/                 # Business logic (orchestrates domain + infra)
├── domain/                  # Entities, value objects, enums (no framework deps)
├── repository/              # Spring Data JPA interfaces
├── infrastructure/          # Capability interface implementations
│   ├── messaging/           # KafkaMessagePublisher
│   ├── cache/               # RedisCacheProvider
│   ├── storage/             # S3ObjectStorageProvider
│   ├── secrets/             # VaultSecretProvider
│   └── fallback/            # In-memory fallback implementations
├── config/                  # Spring @Configuration classes
└── {ServiceName}Application.java  # Spring Boot main class
```

## Conventions

- One aggregate root per bounded context.
- One repository per aggregate root.
- Services depend on capability interfaces, never on infrastructure classes directly.
- DTOs live in `controller/dto/`, never in `service/` or `domain/`.
- Fallback implementations are activated via `@Profile("fallback-{capability}")`.
