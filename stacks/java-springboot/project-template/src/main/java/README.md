# Application Source Placeholder

This base template intentionally does not generate application source before a Plan and milestone-specific Implementation Plan have been approved.

The implementation plan must identify:

- package/base namespace;
- API and domain behavior;
- exact production and local adapters;
- tests to write first and the expected RED result;
- minimum GREEN implementation;
- refactoring boundaries;
- build and verification commands.

Create only the packages and classes required by that approved plan. The presence of `pom.xml` and configuration files does not make this skeleton a runnable or production-ready service.
